# Stage-0 bench wiring — NO-SOLDER variant (XIAO ESP32S3 Sense in the Expansion Board Base)

Drawing: `out/wiring_stage0_solderless.svg` / `.png` (generated by `wiring_stage0_solderless.py`). The soldered breadboard rig is `wiring_stage0.md`; this page replaces it for an owner who does not want to pick up an iron. Pin map = `BOARD_XIAO_ESP32S3_SENSE` + `MCRING_XIAO_BASE` (`firmware/ring-esp32s3/src/config.h` + `config_audio.h`), built with `pio run -e xiao_esp32s3_sense_base -t upload`. Kit: `hardware/bom/stage0-devkit-solderless.csv`; sourcing evidence and the unverified items: `docs/research/04-no-solder-sourcing.md`.

**Joint count: 0.** The pre-soldered XIAO seats in the base, the base already carries the button, buzzer, LiPo socket and charger, the haptic driver comes with its motor attached on a Grove module, the accelerometer is a STEMMA QT board fed from a Grove→QT cable, and the one (optional) interrupt wire is a jumper into the base's female breakout header. The optional speaker amp is the only part whose header holes are unsoldered (its speaker terminal block is pre-soldered) — press-fit pins, five joints at a makerspace, or wait for stage 1 where the amp is on the board.

## What the `MCRING_XIAO_BASE` build changes (`config_audio.h`)

| Define | Stock XIAO build | `xiao_esp32s3_sense_base` | Why |
|---|---|---|---|
| `PIN_BUTTON` / `PIN_BUZZER` | 2 / 4 | 2 / 4 (restated) | the base's button is on D1 and its buzzer on A3 = D3 — same pins; restated so a base revision is a one-line change |
| `PIN_HAPTIC` | 3 (D2, DRV EN) | −1 | D2 is the base's microSD chip-select; the Grove module's EN is tied on-module |
| `HAPTIC_MOTOR_LRA` | 1 | 0 | Grove Haptic Motor is an ERM → `drv2605_init(false)`; autocal still runs |
| `IMU_POLL_MS` | 0 | 25 | the LIS3DH latches its click interrupt, so polling `CLICK_SRC` catches taps when INT1 is not jumpered |
| `PIN_IMU_INT` | 7 (D8) | −1; 7 with `-DMCRING_IMU_INT_WIRED` (env `xiao_esp32s3_sense_base_tapwake`) | without the jumper D8 floats (it is the SD clock line): no ISR and no EXT1 wake on it, the LIS3DH is powered down in deep sleep and the button wakes the ring |
| `PIN_BATTERY_ADC` | 1 (A0) | −1; 1 with `-DMCRING_BATT_DIVIDER_WIRED` | A0 is an open Grove pin on this rig; a floating ADC could report a bogus low battery |
| `BOARD_NAME` | `xiao-esp32s3-sense` | `xiao-esp32s3-sense+base` (`…+base+tapwake`) | the boot log tells you which build is running |

The IMU driver itself needs no flag: `imu_init()` reads WHO_AM_I at 0x18/0x19 and uses the LIS2DW12 (0x44) or the LIS3DH (0x33) back-end (`src/imu_lis3dh.cpp`). `trigger.cpp` sees the LIS2DW12 `TAP_SRC` bit layout for both.

* Seeed **Expansion Board Base for XIAO** (103030356; Adafruit 5033)
* Seeed **Grove – Haptic Motor** (105020011): DRV2605L + ERM, one Grove plug
* Adafruit **LIS3DH STEMMA QT** (2809) or SparkFun Micro LIS3DH Qwiic (SEN-29529)

* USB-C data cable; Bluetooth headphones paired to the laptop/phone (that is where answers come out — the ring speaker is optional)

## Check before power-on

1. XIAO orientation in the base socket: USB-C toward the base's USB end, D0 at the base's D0 silkscreen. A reversed board is dead.
2. Sense board fully clicked onto both B2B connectors; camera FPC latched. The header side of the pre-soldered XIAO is **unverified**: the §1.5 first photo must show the room, not the base PCB.
3. LiPo: red = + on the base's JST silkscreen (a Seeed forum thread reports reversed pigtails on early units; never force a plug). Cell ≥ 400 mAh — the charger is 460 mA.
4. Grove Haptic Motor and the Grove→QT cable sit in the two **I²C** sockets, not in UART (= I²S D6/D7) or A0/D0.
5. LIS3DH INT jumper → **D8** only (never 3V3 / 5V). Leaving it off is allowed: the firmware polls, and the default build ignores D8 (button-only wake). With the jumper fitted, flash `-e xiao_esp32s3_sense_base_tapwake` for tap-to-wake from deep sleep.
6. microSD slot empty (CS = D2, SPI shares D8/D9/D10).
7. Nothing on the 5V header pin. Amp (optional) VIN = 3V3, SD → VIN, GAIN open.
8. Speaker leads only in the amp's +/− terminal block.
9. First power from USB with the cell unplugged, then plug the cell: the base's charge LED lights.
10. Boot log: `fw 0.1.0 (xiao-esp32s3-sense+base)`, `I imu: LIS3DH ready at 0x18 …`, `I drv: DRV2605L ready (ERM)`, `autocal ok`; status flags `0x5e` (camera + IMU + mic + haptic + speaker); `batt=0mV(255%)` is expected (no divider).
11. Deep sleep with the base fitted is milliamps (OLED, RTC, charger, no camera power gate): use the soldered rig or stage 1 for sleep numbers.
12. Flash with `-e xiao_esp32s3_sense_base` (or `…_base_tapwake` with the INT jumper). The stock `xiao_esp32s3_sense` env still boots but drives the ERM with the LRA profile (`autocal FAILED`) and toggles D2 — the base's SD CS — as the haptic enable.
